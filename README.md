# mertozcetin.com

My portfolio. Built with [Astro](https://astro.build) and Claude Code, and stripped to almost
nothing: two typefaces, three colours, no framework, no runtime JS dependencies.

**Live:** [mertozcetin.com](https://mertozcetin.com)

## Running it

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output -> dist/
```

Node 18+. There is no backend, no database, and no API key to set — it builds to static files.

## Dependencies

Three, and only one of them is code:

| | |
|---|---|
| `astro` | the static site generator |
| `@fontsource-variable/bodoni-moda` | display face, self-hosted |
| `@fontsource/ibm-plex-mono` | mono face, self-hosted |

`puppeteer-core` is a dev dependency, used only to render the artifact captures on `/work`. It never
ships to the browser.

## How it's put together

```
src/
  data/site.js        every string and project on the site — one source of truth
  layouts/Base.astro  the shell: fonts, theme boot, the shared duotone filter
  components/         Hero, Marquee, Capabilities, WorkArtifact, Chrome …
  scripts/            theme.js, motion.js, plate-canvas.js, duotone.js — all vanilla
  styles/tokens.css   the design system: colour, type scale, motion
public/img/work/      real artifact captures, generated by scripts/shoot-artifacts.mjs
```

A few decisions worth knowing if you're reading the code:

**The field is the colour.** The background *is* ultramarine, not a dark page with blue accents. Light
and dark swap the field and the type and keep the ember accent, so they're one system rather than two
designs. `--accent` is a different hex per theme on purpose: `#ff5a1f` on bone is 3.69:1 and fails
WCAG AA, so light mode uses `#b83a0c`.

**Colour means "real".** Every screenshot on `/work` is held at neutral grey by a duotone filter and
lifts to full colour on hover. It's the one place colour exists, and it's the site's signature.

**The plates are drawn in code.** The agent graphs are seeded canvas (`plate-canvas.js`) and the
flow/contour plates are build-time SVG (`Plate.astro`), both off a mulberry32 PRNG — so a seed means the
same picture every build. Nothing is stock art.

**Two voices.** Bodoni Moda carries the display; IBM Plex Mono carries the system. The character-decode
effect runs only on the mono, because only a fixed-width face can scramble without the line jittering.

**Reveals animate, they don't transition.** Astro scopes a component's `.foo` to `.foo[data-astro-cid-x]`
— the same specificity as `.reveal.in` — so a component setting `transition:` on a revealing element used
to silently replace the fade. Animations can't be clobbered that way. For the same reason, no component
here takes a `class` prop: a class passed *into* a component lands with the child's scope hash and the
parent's rule never matches. Parents wrap instead.
